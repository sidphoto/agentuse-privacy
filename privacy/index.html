AgentUse｜隱私權政策

開發者：家河有品 ・ 生效日期：2026 年 10 月 28 日

AgentUse 是家河有品自己使用的社群發文工具，只管理我們自己經營的帳號，不開放給外部使用者，也不收集其他人的個人資料。

1. 這個工具做什麼

透過 Meta 官方 API，把經過人工核准的內容發布到我們自己經營的 Facebook 粉絲專頁、Instagram 和 Threads 帳號，並查詢這些帳號的基本資訊（帳號 ID、名稱）和貼文連結，用來確認發文成功。

2. 會處理哪些資料

只處理我們自己帳號的資料：存取權杖（token）、帳號 ID 與名稱、我們發布的貼文內容、貼文 ID 和連結。

不讀取、也不保存追蹤者或其他使用者的個人資料、留言或私訊。

3. 資料存放在哪裡

token 和發文紀錄只存放在營運者自己的電腦，檔案權限限制為本人可讀。不上傳到其他伺服器，不分享、不出售，也不用於廣告。

4. 第三方

AgentUse 只和 Meta（Facebook、Instagram、Threads）的 API 往來。Meta 如何處理資料，請見 Meta 隱私政策。

5. 撤銷授權與刪除資料

在 Facebook 或 Instagram 的「設定 › 應用程式和網站」移除 AgentUse，就會撤銷它的存取權。你也可以寫信給我們要求刪除相關資料，我們會在 30 天內刪除本機保存的 token 和紀錄並回信確認。
